# AI Job Search Assistant (CLI)

> **Персональный консольный AI-ассистент для поиска работы, адаптации резюме и подготовки к собеседованиям.**  
> Работает прямо в вашем терминале в связке с AI-агентами (**Google Antigravity**, **Claude Code**, **Cursor**, **Codex**).

---

## 💡 Что делает этот проект?

Поиск работы — это рутина: сотни однотипных страниц, постоянная подгонка резюме под ключевые слова и написание сопроводительных писем.

Этот инструмент берёт эту рутину на себя:
1. **🔍 Ищет вакансии** по вашим критериям на джоб-бордах и кэширует их.
2. **⚖️ Анализирует соответствие (Fit Score 0–100):** проверяет знание языков (*Language Gate*), вилку зарплат, формат работы (Remote/Hybrid) и стек.
3. **📄 Генерирует адаптивные отклики:** под каждую вакансию создаёт уникальное LaTeX-резюме (`.tex` $\to$ `.pdf`) и сопроводительное письмо, подсвечивая именно те ваши реальные навыки, которые нужны работодателю.
4. **🛡️ Принцип Zero Fabrication:** агент никогда не врёт и не придумывает несуществующий опыт. Если чего-то в вашем профиле нет — модель честно укажет это как точку роста.
5. **🎙️ Готовит к собеседованиям:** генерирует STAR-истории (Situation, Task, Action, Result) под конкретную компанию.
6. **📊 Ведёт учёт:** автоматически фиксирует все отклики и статусы в `job_search_tracker.csv`.

## ⚡ Быстрая установка

### 🪟 Windows (в одну команду)
Откройте **PowerShell** и вставьте:
```powershell
powershell -ExecutionPolicy Bypass -c "irm https://raw.githubusercontent.com/hellstumy/aijobclean/main/install.ps1 | iex"
```
*(Скрипт сам проверит Python, создаст окружение и запустит консольный мастер настройки).*

---

### 🐧 Linux / macOS
```bash
git clone https://github.com/hellstumy/aijobclean.git
cd aijobclean
python3 setup_wizard.py
```

## 🚀 Пошаговое руководство: как пользоваться

Вся работа с проектом происходит в консоли за 3 простых шага:

### Шаг 1. Первичная настройка профиля
При первом запуске скрипт [`setup_wizard.py`](setup_wizard.py) задаст несколько базовых вопросов в терминале:
- Ваше имя, город, контактный email
- Желаемая должность (например: *Frontend Developer*, *Python Backend*, *DevOps*)
- Формат работы (удалённо, гибрид или офис)
- Владение языками (например: *English B2, Russian Native*)

Затем скрипт создаст файл **`skills_checklist.md`**, в котором сгенерирует список ключевых технологий для вашей специальности. Откройте его в любом текстовом редакторе, отметьте ваши навыки (`[x]` или `y`) и нажмите **Enter** в консоли.

> *Профиль готов! Все данные записаны в локальные канонические файлы проекта в папке `.claude/skills/job-application-assistant/`.*

---

### Шаг 2. Запуск AI-агента и основные команды

Откройте терминал с вашим AI-агентом в папке проекта (**Google Antigravity**, **Claude Code** или терминал **Cursor**).  
Общайтесь с агентом с помощью слэш-команд или обычными фразами:

#### 1. Поиск новых вакансий
```text
/scrape
```
*(или: «Найди свежие вакансии»)*  
Агент сканирует доступные порталы (LinkedIn, FreeHire и др.) по вашим поисковым фильтрам и сохраняет их в базу `job_scraper/seen_jobs.json`.

#### 2. Оценка соответствия
```text
/rank
```
*(или: «Оцени найденные вакансии»)*  
Агент прогоняет вакансии через матрицу оценки: отсеивает неподходящие по языку или локации и выставляет баллы соответствия вашему стеку (Strong Fit, Good Fit, Veto).

#### 3. Подготовка индивидуального отклика
```text
/apply https://example.com/job-posting-url
```
*(или: «Подготовь отклик на эту вакансию: [ссылка]»)*  
Агент:
- Выделит ключевые требования вакансии;
- Сформирует адаптированное резюме в `cv/main_<company>.tex`;
- Напишет индивидуальное сопроводительное письмо в `cover_letters/cover_<company>.tex`;
- Автоматически внесет запись в трекер откликов `job_search_tracker.csv`.

#### 4. Подготовка к собеседованию
```text
/interview НазваниеКомпании
```
Агент проанализирует профиль компании и составит для вас шпаргалку: технические вопросы, которые вам могут задать, STAR-примеры из ваших проектов и вопросы, которые стоит задать интервьюеру.

#### 5. Фиксация результата
```text
/outcome НазваниеКомпании applied
```
Обновляет статус отклика в трекере (`applied`, `interviewing`, `offer`, `rejected`).

---

### Шаг 3. Компиляция резюме в PDF

Для сборки сгенерированных `.tex` файлов в аккуратные PDF-документы используется LaTeX:

- **Windows:** Установите [MiKTeX](https://miktex.org/download) (или `winget install ChristianSchenkJ.MiKTeX`).
- **Ubuntu/Debian:** `sudo apt install texlive-latex-extra texlive-fonts-recommended`
- **macOS:** `brew install --cask mactex-no-gui`

**Команды сборки:**
```bash
# Сборка резюме:
lualatex cv/main_example.tex

# Сборка сопроводительного письма:
xelatex cover_letters/cover_example.tex
```

## 📁 Структура проекта

```text
aijobclean/
├── setup_wizard.py         # Консольный мастер настройки профиля и навыков
├── skills_checklist.md     # Чек-лист навыков под вашу должность
├── job_search_tracker.csv  # Таблица учета всех поданных заявок
├── install.ps1             # Скрипт автоматической установки для Windows
├── cv/                     # Шаблоны и сгенерированные LaTeX-резюме
│   └── main_example.tex    # Базовое мастер-резюме
├── cover_letters/          # Шаблоны и тексты сопроводительных писем
├── .claude/skills/         # Единый источник правды (база знаний о кандидате):
│   ├── 01-candidate-profile.md   # Факты биографии, контакты, стек
│   ├── 02-behavioral-profile.md  # Рабочий стиль и мотивация
│   ├── 04-job-evaluation.md      # Критерии отбора вакансий и стоп-факторы
│   └── job-scraper/              # Поисковые запросы и порталы
└── tools/                  # Консольные утилиты ранжирования и валидации
```

## 🛡️ Безопасность и приватность

- **Все данные хранятся локально на вашем компьютере.**
- Репозиторий изначально полностью очищен от чужих персональных данных.
- Ваши личные контакты, сгенерированные PDF и история поиска находятся в файлах, защищенных правилами `.gitignore`. Если вы захотите запушить свой форк на GitHub, рекомендуем делать репозиторий **Private**.
